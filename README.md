# Space Invaders

**Versão da Unity utilizada:** 6000.4.0f1

## Como executar

1. Extraia o arquivo **Build.zip** para uma pasta de sua preferência.
2. Abra a pasta extraída.
3. Execute o arquivo **SpaceInvaders.exe**.

Não é necessária nenhuma instalação adicional.

## Controles

* **WASD** ou **Setas direcionais**: movimentar a nave
* **Espaço**: atirar
